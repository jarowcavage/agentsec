# Identity security narrative

Discovery: who owns your non-human identities, who certifies their access, and how quickly can you revoke them?

Use the Identity security narrative in Overview. Start with Agent identities: owner, declared permissions, tool mapping, activity timestamps and short-lived credential metadata. Missing owner, uncertified access and lack of observed activity are transparent flags, not an AI risk score. Register an unowned synthetic agent, assign an owner and certify access as administrator.

Connect governance to a business workflow: investigate the sample dependency, request a narrowly scoped issue capability and show that an analyst cannot approve it. Approve as administrator, execute once and show replay denial. Run the unauthorized-write demonstration and inspect its audit event. Suspend the agent and show investigation blocked at the MCP boundary.

The business value hypothesis is bounded automation with accountable ownership. Measure approval waiting time and authorized/denied operations; use a pilot to determine operational impact. This is not a SailPoint integration, an identity discovery connector or production IAM. Local persona switching is demonstrative, not enterprise authentication; connected GitHub approval uses a separate password.
