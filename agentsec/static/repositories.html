What does this check—and what does it miss?

What we check

Python: exact versions in requirements*.txt.

JavaScript / TypeScript: packages in npm lockfiles (versions 2 and 3), including indirect dependencies. Without a lockfile, only exact versions in package.json.

Every matched vulnerability is listed—not just one.

What we don’t check

This checks third-party packages, not your application’s own code. It does not find SQL injection, exposed secrets, or prove that a vulnerability can be exploited in your app.

Other languages, version ranges and unsupported lockfiles are reported as gaps. Up to 40 dependency files and 250 distinct package versions per scan.
