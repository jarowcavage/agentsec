What actually runs

  1. FastAPI starts a bounded investigation and persists state in SQLite.
  2. LangGraph routes between structured model decisions and typed MCP tools. The model selects the next tool; completion criteria are enforced independently.
  3. The gateway reserves estimated cost before calling OpenAI. Unknown charges stay reserved. Maximum 10 calls, 900 output tokens/call and a seven-minute run deadline.
  4. Server-issued process credentials bind MCP calls to one investigation. Permission and revocation checks occur before each tool.
  5. Verified PyPI wheels are inspected in isolated workspaces. Fixed tests run with network disabled under macOS Seatbelt or a restricted Docker container.
  6. A short-lived human grant binds local publication to the exact patch hash. Consumption prevents replay.

Trusted boundaries: server, local database and curated test harness. This is not multi-tenant SaaS. Replay is a hash-checked recorded live run, not a new investigation. The deterministic policy challenge is separate from model behavior.

Local demo personas are not enterprise identity federation. GitHub writes remain in the separately configured governance console.
